# 秒遮 — 第一版界面文案（v1.0）

版本 1.0 · 2026-11-23 · 负责人 Camo (@naming)
依据：简报 1.1。东西放在哪、长什么样以 Colo 的规格为准；字以这里为准，别处不改写。

怎么用这份文件：
- 简体是正本，繁体和英文逐条对着简体。Steve 的手机是繁体界面，繁体不是回头补的。
- 编号固定。以后改字不改编号，不用的句子留着标「停用」。
- 界面上的字都在「」里。

## 1. 名字

- 中文名：秒遮（简体、繁体写法一样）
- 英文名：QuickCover
- 后缀：quickcover，也就是 `sb.moe.quickcover` 和 `quickcover.airhost.site`
- 标语：
  - 简体：「一秒遮住，放心发。」
  - 繁体：「一秒遮住，放心傳。」
  - 英文：Covered in a second. Send without worry.
- 图标下的名字：简体「秒遮」· 繁体「秒遮」· 英文 QuickCover
- 标语用在商店页和网页上。第一版界面里不放：3.2 那页的正文已经把话说完了，再加一句标语就成了广告。
- 用名字的两条规矩：
  - 名字只当名词用，正文里不说「秒遮一下」。
  - 「秒」只出现在标语里，别处不承诺几秒。
- 重名：中文没搜到同名应用。英文 QuickCover 有一个同名的 Shopify 插件（标了注册商标）和一个已经停用的求职信工具，没搜到同名的 iOS 应用。这是搜到的结果，不是查清了；要上架再查一遍。

规矩：

- 5.1 和 5.2 出现时，把标题念出来一次。
- 「按住看原图」读屏的人按不了。要给一个开关代替，字用 7.3；开着就是显示原图。这一条要 Colo 和 Pluso 定怎么放。

## 8. 不这么写

- 不写「不联网」「任何数据都不上传」。先自用还是上架没定，上架可能要接崩溃上报。能写的是「图片不离开手机」。
- 不写「识别」「检测」「算法」「AI」「模型」「敏感信息」「脱敏」「OCR」「元数据」。换成 §2 里对应的词。
- 不写「绝不」「百分百」「保证」。
- 不在界面上出现 redact，中英文都不出现。
- 清单里不写被遮的内容本身。

## 9. 还没定的

- 先自用还是上架：Steve 没选。定了以后才做商店那一页（名称、副标题、关键词、简介）和英文重名复查。
- 系统弹窗要的是哪一种权限：Pluso 定。如果要的是整个相册，3.2.3「允许访问截图」要跟着改成和弹窗一致的说法。
- 3.2.5「秒遮只读「截图」相簿」：Pluso 确认只读这一个相簿后再决定加不加。
- 6.2.4「遮住的内容不会留在新图里」：验收第 3 条过了才留。
- 「按住看原图」的读屏替代：等 Colo、Pluso 定。
