版本 1.6 · 2026-11-24 · Colo（@design）
依据：简报 `docs/ios/brief.md` 1.5、文案 `docs/ios/copy.md` 1.9。界面上的字只从 copy.md 按编号取，这份文件不另写一句。
可点的样机：<https://airbuild.page/a804c16b-33d0-4405-b933-6ef81e8da3c9>。右栏「状态」切编辑页会遇到的九种情况，「屏幕」切各页，「方案」切繁體 / 简体 / English。样机整个是深色，强调色就是青綠；右栏的「外观」不用切。

## 0. 怎么读

- 长度一律 pt；颜色给 sRGB 十六进制（整个 App 只有深色一种外观，§11.1）；字体给 SwiftUI 的 `Font.TextStyle`。
- 「一项」就是图上的一块，也是逐项检查里的一行（简报 §6）。一块遮盖对一个开关。一个值被折到两行，画出来是两块，算一项：逐项检查里一行、一个开关，两块一起开、一起关。挨得近的几列黏成一串，也是一块、一项。逐项检查和顶上的汇总数的都是块（Ato，2026-11-23）。
- 「3.1.1」这种编号都指 copy.md。本文引号里的界面字是繁体，因为 Steve 的手机是繁体；简体和英文在 copy.md 同一行。

- 1.2 改了什么：补一句——黏成一串是一块、一项（Ato 定，简报 §6）。

- 1.4 改了什么：选图页、导出页的返回键改成 iOS 26 系统的圆箭头，不带「編輯」两个字（§5、§7.1.1、§7.5.1）；导出页的 8 张截图重截。

## 1. 方向

一句话：**黑底上，图是唯一亮的东西。** 强调色只标两件事——能点的东西，和选中的工具。

| 选择 | 值 | 理由 |
|---|---|---|
| 编辑页背景 | 纯黑 `#000000`，不放标题、不放说明 | 用户在这里只做一件事：看一眼遮好没有，发出去。多一个字都在挡图 |
| 其余各页的形状 | 系统分组样式：黑底、深灰卡片、最小高 52 的行 | iOS 用户最熟的形状，自用版不值得重新教 |
| 强调色的用量 | 只给遮盖的边、选中的工具、主按钮、行首小图标 | 聊天截图本身颜色就多，界面再花就看不出哪一块是遮盖 |
| 找到之后 | 直接盖上，图上不画框 | 看到的是结果，不是过程（简报 §6）。只有定位某一项和自己拖框时才画边 |
| 提醒放哪 | 跟着它说的东西走：模糊的提醒在样式分段下面（§7.4），存的提醒在按钮上面（§7.5） | 在用得上的地方说一次，不弹窗、不挡图 |

不做的（简报 §8：先自用）：启动页、引导轮播、设置页、商店页、在界面上解释技术。

- 行里的字最多两行；说明字最多三行；都不截断成省略号。

## 5. 页面和怎么走

| 页面 | 怎么出 | 小节 |
|---|---|---|
| 引导页 `PrimerScreen` | 第一次打开、还没有照片权限时，打开就在这一页 | §7.2.1 |
| 选图页 `PickerScreen` | 引导页点了「先選一張圖」；没有权限时打开就在这一页；编辑页点「換一張」推上来 | §7.1 |
| 编辑页 `EditorScreen` | **根页面**。有全部照片权限时打开直接到这里，载入最近一张截图 | §7.3 |
| 逐项检查 `ReviewSheet` | 编辑页点「逐項檢查」，从下面出来的面板，能拉到全屏 | §7.4 |
| 导出页 `ExportScreen` | 编辑页点「匯出」，推上来，不弹确认 | §7.5 |
| 系统照片选择器 | 选图页前三行，或编辑页「換一張」之后的同一页 | §7.1.2 |
| 系统分享面板 | 导出页「分享」 | §7.6 |
| 系统警告「這張圖打不開」 | 选了打不开的文件 | §7.1.4 |

- 编辑页没有导航栏，也没有返回键；上面的状态栏字是白的。其余各页是系统的导航栏（高 44，标题居中 `.headline`），左上角是系统返回键。**它是 iOS 26 的圆形玻璃箭头，不带字**：编辑页藏了导航栏，系统就没有名字可写。不自己画返回键去换回「編輯」两个字，自己画的和系统的不完全一样，还容易弄丢边缘右滑。读屏照系统的念法念出上一页的名字 4.1.1「編輯」。选图页是根的时候没有返回键。
- 选图页、导出页都能从左边缘滑回去。编辑页不让滑返回（它是根）。
- 去导出页、去选图页、开逐项检查都是系统默认的过场，不自己写动画。

结构照这个摆，名字随意：

```swift
NavigationStack {
    EditorScreen()                         // 根：黑底、没有导航栏
        .navigationDestination(for: Route.self) { route in
            switch route {
            case .picker: PickerScreen()
            case .export: ExportScreen()
            }
        }
        .sheet(isPresented: $model.reviewShown) { ReviewSheet() }
}
```

- 编辑页用 `.toolbar(.hidden, for: .navigationBar)`，并在最外面挂 `.preferredColorScheme(.dark)`：整个 App 都是黑底、白字、青綠，不跟系统变（§11.1）。
- 系统照片选择器、系统分享面板、系统警告都用系统自己的，不改外观、不改字（里面我们自己的那句见 §7.2.2）。它们跟着 App 是深色（未验，§12.2）。

## 6. 通用组件

**玻璃条（编辑页底部）**
- 一条 Liquid Glass：`.glassEffect(.regular, in: .capsule)`，外面用 `GlassEffectContainer` 把它和顶部的两个玻璃按钮装在一起。不染色、不加描边。
- 里面从左到右：還原（`arrow.uturn.backward`）、重做（`arrow.uturn.forward`）、手動框選（`rectangle.dashed`），一段可伸缩的空位，然后「匯出」。图标按钮之间间隔 6。
- 图标按钮：44×44 的玻璃圆，图标 21，白色。按下去缩到 0.94（0.12 秒）。没有东西可以還原 / 重做的时候图标 42% 不透明，仍留在原位，不收起来。
- 选中的工具（点了「手動框選」之后）：玻璃圆换成实色的青綠 `#6FE0DA`，图标 `#0B3B3F`。

#### 7.3.2 找到了 `7-3-2-found.png`、照片 `7-3-photo.png`

- 图清清楚楚，该遮的都盖上了。页面上没有标题、没有数字（数字在逐项检查顶上，§7.4）。
- 一块遮盖就是一项。规则命中一段连续文字的一部分时，整段一起遮，宁可多遮（Ato，2026-11-23）。一个值被折到两行，画出来是两块，算一项：逐项检查里一行、一个开关，两块一起开、一起关。挨得近的几列被读成一行、黏成一串时也是一块、一项：逐项检查里一行、一个开关，不管串里命中了几条规则。逐项检查和顶上的汇总数的都是块，不是规则的命中数，两边的数一致——不然一块变成两三行、几个开关管同一块像素，关掉一个什么也露不出来（Ato，2026-11-23）。
- 遮盖的样子跟着当前样式（默认马赛克，§7.4 底部能换，换过会记住）：

| 样式 | 画法 |
|---|---|
| 马赛克 | 把盖框切成格子（行数、列数见下），每格一个颜色，是它下面像素的平均；放大回去不插值。盖住的地方看不出原来的字 |
| 模糊 | 同一张格子图，放大时插值抹平，看不出格子的边；圆角 4 |
| 纯色 | `#000000`；圆角 4 |

- 遮盖就是找到的那一块，留边已经在里面（文字上边半个框高，下边和左右 0.2–0.25 倍框高；车牌四边 0.35–0.5 倍；人脸按简报 §6 的数），界面不再另加。
- 格子怎么切。数都在导出的图上量，单位 px；「盖框」是这一块遮盖的框，T 是系统圈出这行字的那个框的高，也就是一个字高（17 pt 的字在截图上 T = 51）。
  1. 文字类的一块——手機號碼、身分證號碼、銀行卡號、電子郵件、網址、IP 位址、長串數字、可能是車牌，和遮上的文字行：盖框高够 2T、而且一半够 12 px，就是两行格，每格盖框高的一半；不够就是一行格，格高等于盖框高。一行字的盖框高 1.7–1.75T，不够 2T，所以一行字是一行格（T = 51 时格子高 87–89）；一块占几行字，也最多两行格。
  2. 二维码、条形码：没有字高，两行格，每格盖框高的一半。
  3. 手画的框：没有字高，一行格，格高等于盖框高。
  4. 人脸：格子是盖框高 ÷ 6，行数是盖框高 ÷ 格子、进一，盖框够 72 px 高就是六行。这一条照实机，没动；1.5 以前写的「图缩到宽 48 px」是错的。
  5. 格子的高不到 12 px 时取 12 px。
  6. 列数是盖框的宽除以格子的高，除不尽进一；每格的宽是盖框的宽除以列数。左右、上下都正好分完，不往外贴（只第 5 条多出来的往下贴）。
- 盖上的时候从 0.6 放大到 1，0.26 秒；所有块同时出现，不排队（§8）。
- 默认遮的（copy.md §4.5）：人脸、手机号、身份证号、银行卡号、邮箱、网址、IP、长串数字、可能是车牌、二维码、条形码。默认不遮的只有「文字」，图上原样显示，什么都不画。

- 底下的「還原」「重做」在没有东西可還原、可重做时是 42% 不透明。

## 8. 动效和触感

动效只做一件事：让人看见哪一块变了。不为好看加。

| 什么时候 | 怎么动 | 时间 |
|---|---|---|
| 找完，遮盖出现 | 每一块从 0.6 倍、全透明起，放到 1 倍，略过冲（弹簧，bounce 0.2）；所有块同时出现，不排队 | 0.26 秒 |
| 开始找 / 找完 | 图模糊 14 → 清楚 | 0.25 秒淡 |
| 点开关 | 那一块全透明 ↔ 不透明，不缩放 | 0.2 秒 |
| 换样式 | 所有遮盖交叉淡入淡出 | 0.2 秒 |
| 图上的胶囊（4.2.1、4.8.4、4.8.6）出现、收起 | 只淡入淡出，不挪动 | 0.2 秒 |
| 提示卡出现、收起 | 图缩到放得下卡的大小，卡淡入；收起反过来 | 0.3 秒 |
| 按住看原圖 | 遮盖一起淡掉，松手回来。按住满 350 ms 才开始，避免和滚动、缩放手势抢 | 0.15 秒 |
| 在图上定位一项 | 亮一圈边：亮 0.7 秒，再淡 0.6 秒 | 共 1.3 秒 |
| 玻璃按钮按下去 | 缩到 0.94 | 0.12 秒 |
| 主按钮、次按钮、小按钮按下去 | 0.8 不透明 | 0.1 秒 |
| 导出页的 toast | 淡入并从下 8 pt 升，停 1.6 秒，淡出 | 0.25 / 0.3 秒 |
| 逐项检查面板、导出页、选图页、警告 | 系统的过场 | 系统 |

- 「正在找」的转圈：16 pt，0.8 秒一圈，匀速。
- 提示卡（§7.3.5）5 秒没人碰就自己收起；下一次进编辑页，情况没变就再出。
- 两张图之间换（「換一張」选好了）：新图淡入 0.2 秒，旧图不缩小、不滑动。

触感只有四处，其余都不加——编辑页上每点一下都震会很吵：

| 什么时候 | 触感 |
|---|---|
| 自己框出一个框，手松开框合上 | 轻（`UIImpactFeedbackGenerator(style: .light)`） |
| 儲存到照片成了 | 成功（`UINotificationFeedbackGenerator`，`.success`） |
| 儲存到照片没成 | 错误（同上，`.error`） |
| 换样式 | 选（`UISelectionFeedbackGenerator`） |

- 开关、玻璃按钮、系统分段控件用系统自己的，不加。
- 手感只在真机上试才算数（未验，§12）。

「减弱动态效果」开着时：遮盖直接出现，不放大道；图直接清楚；定位的边直接亮、到时直接灭，不渐变；图不缩放让位给提示卡，卡直接出。面板和页面的过场是系统的，自己跟。用 `@Environment(\.accessibilityReduceMotion)` 判断。

## 9. 读屏和无障碍

### 9.1 编辑页的读屏顺序

从左上到右下：換一張（4.1.2）→ 逐項檢查（4.4.1）→ 提示卡（有就先念：标题、正文、按钮）→ 還原（4.8.1）→ 重做（4.8.2）→ 手動框選（4.8.3）→ 匯出（4.9.1）。

- 图和图上的遮盖不是读屏元素：它们没有能念的东西，被遮的内容也规定不念（copy.md §7）。想逐项知道遮了什么，走逐项检查。
- 图上的胶囊：4.2.1「正在找要遮的地方…」出现时念一次，之后不进顺序（那两个玻璃按钮这期间不能点，等它们恢复就能接着走）；4.8.4、4.8.6 不进顺序。「看原圖」开没开，由逐项检查里那个开关来念。
- 還原、重做没东西可做的时候，按钮还在顺序里，读成「還原，已變暗」（`.disabled(true)` 的系统读法），不藏起来——藏了会让人以为按钮没了。

### 9.2 每个元素怎么念

| 元素 | 名字 | 状态 | 提示（hint） |
|---|---|---|---|
| 換一張 | 4.1.2 換一張 | 按钮 | — |
| 逐項檢查 | 4.4.1 逐項檢查 | 按钮 | — |
| 還原 | 4.8.1 還原 | 按钮；能做 / 已變暗 | — |
| 重做 | 4.8.2 重做 | 按钮；能做 / 已變暗 | — |
| 手動框選 | 4.8.3 手動框選 | 按钮；选上了加「已選取」 | — |
| 匯出 | 4.9.1 匯出 | 按钮 | — |
| 提示卡的标题、正文 | 5.1.1、5.1.2 等 | 静态文字，一次念完 | — |

### 9.3 逐项检查

- 打开面板时念标题 4.4.1 一次（`AccessibilityNotification.ScreenChanged`，或让面板成为 `.accessibilityElement(children: .contain)` 并用 `AccessibilityFocusState` 把焦点放到标题上）。
- 汇总一行用 7.1：「找到 2 張人臉、5 處文字、1 個 QR Code」。它不是写死的一句，是拼出来的（copy.md §7）：先「找到」（英文 Found），后面接汇总里有的各项（4.3.1–4.3.4），中文用「、」连，英文用逗号连、最后一项前面加 and；没有的类不念，数字由程序填，顺序同画面（§7.4.2）。它是静态文字，不是按钮。

  - 名字：那一行的字（「手機號碼」「人臉 2」）；带小字的行把小字跟在后面念（4.5.14、4.6.2）。
  - 状态：4.5.15「已遮」或 4.5.16「沒遮」（`.accessibilityValue`）。
  - 提示：7.2「點兩下切換遮或不遮」。点两下 = 切换开关。

- 「遮住所有文字」：名字 4.6.1，后面念 4.6.2，状态同上。
- 4.4.3 那一行提醒：念 4.4.3，然后是按钮 4.8.3「手動框選」（同一句字，点了关面板、进拖框）。

- 全部文字用 §3 的 `Font.TextStyle`，跟 Dynamic Type 走，没有写死的字号。

## 10. 图标和符号

### 10.1 App 图标

一张 1024×1024 的方图，不带圆角、不带透明：圆角由系统裁，透明通道 App Store 不收。文件都在 `docs/ios/icon/`：`AppIcon.appiconset/`（PNG、SVG 源、`Contents.json`）和 `IconArtwork.imageset/`。

画法（坐标都在 1024 的格子里）：

1. 底 `#121214` 铺满。
2. 一个白圆 `#FFFFFF`：圆心 (512, 512)，半径 292（直径是画布的 57%）。
3. 一条横带压在眼睛的位置：x 212–812、y 408–572（高 164），颜色同底，裁在白圆里面。
4. 带里四个方块，各 120×120，上边都在 y 430，左边 x 254 / 386 / 518 / 650（间隔 12，带的上下各留 22）。颜色从左到右 `#C9F7F4`、`#6FE0DA`、`#0B7A7A`、`#3DBDB6`。
5. 一笔笑：从 (438, 646) 到 (586, 646) 向下弯的弧，线宽 34，圆头，颜色同底。

- 为什么是这张脸：App 做的事就是「把眼睛那一条换成马赛克」，一眼能讲完；只有白圆、彩带、笑三个形状，60 pt 也认得出（`10-1-icon.png` 最右一栏），深浅壁纸上都立得住。
- 为什么用强调色：桌面上只有这一个地方能放颜色，和界面里的按钮同色，打开 App 不换调子。颜色就是 §2 的青綠：第 2 块用 `AccentColor`，第 3 块用 `AccentButton`；第 1 块比强调色浅一档，第 4 块深一档，这两个只用在图标上。
- 深色、染色的主画面外观：不给单独的图，系统自己生成。自用版不做分层的 `.icon`。
- 没有光泽、没有描边、没有投影：这些系统都会加，自己加了会叠两层。

`10-1-icon.png`：左边是方图，中间是浅色壁纸上的样子，右边是深色壁纸上的样子。

### 10.2 引导页上那张画

§7.2.1 的那张画就是同一个图标，不裁圆角，132 pt，用 `IconArtwork.imageset`（132 / 264 / 396 px）。显示的时候自己裁：

```swift
Image("IconArtwork")
    .resizable()
    .frame(width: 132, height: 132)
    .clipShape(RoundedRectangle(cornerRadius: 29.5, style: .continuous))
    .overlay(RoundedRectangle(cornerRadius: 29.5, style: .continuous)
        .strokeBorder(.white.opacity(0.14), lineWidth: 1))
```

29.5 是 132 的 22.37%，和系统裁主画面图标用的差不多。`.continuous` 让四个角的弯和系统的一致。

不要投影：页面是黑的，投影看不见。图标自己的底 `#121214` 只比页面亮一点，所以沿边加一圈 1 pt 白 14% 的边，让人看出这是一个圆角方块（§7.2.1）。不做浅色外观（§11.1），所以没有浅色页的做法。

## 11. 外观、语言、字号

### 11.1 外观：整个 App 都是黑的

- 所有页面都按深色画，不跟手机的浅色 / 深色设置变。一行就够：`NavigationStack` 最外面挂 `.preferredColorScheme(.dark)`。
- 值都在 §2 的表里：页面底 `#000000`、卡片底 `#1C1C1E`、正文白、次要字 `#A5A5AA`、能点的字和行首图标 `#6FE0DA`、主按钮的底 `#0B7A7A`。
- 不做浅色外观：Steve 定了全黑（2026-11-23），没有第二套值，§2 的颜色集 Any 和 Dark 两栏填同一个值。样机右栏的「外观」还能切到浅色，只是留着看，不是要做的。
- 为什么不是「编辑页黑、其余跟手机」：编辑页无论如何都是黑的，图在黑底上最清楚；选图、逐项检查、导出都是编辑页的前后一步，一黑到底就不用在两页之间换外观（换了会闪一下），玻璃和弹窗也都是深色的，白字在玻璃上最稳。相机、照片的编辑页都是这么做的。Steve 定了全黑（2026-11-23）。
- 系统的照片选择器、文件选择器、分享面板、警告会跟着是深色（未验，§12.2）。
- 引导页也是黑底。图标自己的底 `#121214` 只比页面亮一点，所以那一圈 1 pt 白 14% 的边代替了投影（§7.2.1）。
- 截图全部是深色外观、青綠强调色下截的（1.3 全部重截），是浏览器里截的样机：没有 SF 字体，引导页那张图标画放大以后边缘有一点锯齿，真机上不会这样。样机的字比真机的系统字体窄一成多（样机那边的宽是 Camo 量的，真机那边是按字宽表估的），英文哪一句会折行以真机为准。做出来的界面以这份规格的数为准，不用去对截图里的像素。文件名 `x-en-` 开头的是英文，`x-hans-` 开头的是简体。

### 11.2 语言

- 界面上的字只有 copy.md 的三种：繁體、简体、English。跟手机的设置走，App 里不设切换。Steve 的手机是繁體，所以本文引号里和样机的默认都是繁體。
- 繁體、简体的长度差不多，排布不变。英文更长，规则只有三条：按钮上的字不换行（放不下就减到 15 pt）；引导页和导出页的说明字多一行就多一行；编辑页顶部两个按钮在英文下左右内边距从 12 减到 10、间隔从 6 减到 5，让它排成一行（`x-en-found.png`）。
- 英文里「QR Code」照 copy.md 写，不翻成别的。
- 英文和简体各屏的截图：`x-en-primer.png`、`x-en-picker.png`、`x-en-review.png`、`x-en-export.png`、`x-hans-found.png`、`x-hans-review.png`、`x-hans-export.png`。

### 11.3 字号

- 全部跟 Dynamic Type（§3），没有写死的字号。
- 到辅助功能档（AX1 起）的做法在 §9.5，没画样机（未验）。
- 图上的胶囊和玻璃条上的字在大字号下会挤：到 AX 档只留图标（§9.5）。
